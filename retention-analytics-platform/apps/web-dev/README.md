# Developer Console (web-dev)

Next.js frontend for platform ops. Consumes the FastAPI API via `/api` rewrites.

Pages:
- `/` — landing
- `/schema` — dynamic entity schema builder (schema-as-data)
- `/workflows` — workflow designer: view + run pipelines
- `/verticals` — pluggable vertical packs (marketing, ecommerce, saas, fintech, healthcare)
- `/tenants` — multi-tenant agency/client hierarchy

Run:
```bash
npm install
npm run dev
```
